# Ada Nav Package Demo

Eden Navigator component designed for iPad 13 Pro landscape orientation.

## Overview
Interactive navigation interface using the iPad_Nav.svg as the base canvas. Built specifically for iPad 13 Pro landscape specifications.

## Structure
- `ada-nav-demo.tsx` - Main navigator component
- `ada-nav-demo.css` - Responsive styling for iPad 13 Pro landscape
- `README.md` - Component documentation

## iPad 13 Pro Specifications
- **Resolution:** 2048 x 1536 pixels
- **Aspect Ratio:** 4:3
- **Orientation:** Landscape
- **Display:** Liquid Retina XDR

## Assets
- `iPad_Nav.svg` - Base navigation canvas (located in `/public/assets/`)

## Usage
```tsx
import AdaNavDemo from './ada-nav-package-demo/ada-nav-demo';

<AdaNavDemo />
```

## Features
- Responsive design for various screen sizes
- SVG-based navigation canvas
- Interactive overlay for navigation elements
- Optimized for iPad 13 Pro landscape viewing
