# Ada AI Orb

This subdirectory contains the AI orb implementation using OGL (WebGL library).

## Setup
- OGL library installed via `npm install ogl`
- WebGL-based 3D graphics and animations
- Integration with Ada Test Pane component

## Structure
- Component files will be created here following kebab-case naming
- OGL imports and WebGL canvas setup
- 3D orb rendering and animation logic

## Dependencies
- `ogl` - Lightweight WebGL library for 3D graphics
