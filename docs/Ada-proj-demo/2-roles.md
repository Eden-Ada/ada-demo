# 2—Roles (Role Assignation)

Purpose: assign either AI agents or people to task blocks; AI can operate as a persona and automate tasks relative to the pipeline.

## Entry point
- Click the plus button at the bottom‑right of the task pipeline.
- Choose AI or Person.

## AI agent (options and behavior)
- Name
  - Enter a custom name or click Random Name to auto‑generate.
- Role
  - Assign a role (e.g., Brand Agent, Design Agent, Production Agent, Marketing Agent, Distribution Agent) or a custom label.
  - The role defines which task‑item slots the agent can decide/execute.
- Profile icon color
  - Pick a color from the palette for quick identification across the canvas.
- Assignment
  - Admin drag‑drops the AI agent onto a task block (or a specific task item).
  - The agent only acts within the scope it’s assigned to.
- Behavior
  - Operates as a user/persona: watches the pipeline, triggers on its assigned tasks when they become active.
  - Executes research/automation, proposes decisions via decision panes, and auto‑advances when configured.
  - Actions are attributed to the agent identity for traceability.
- Controls
  - Pause/Resume automation.
  - Step (run one action) or Override (human takes over) when needed.

## Person (minimal)
- Enter an Eden username; an invite is sent.
- Upon acceptance, drag‑drop the user onto a block.
- Access is scoped: they only see and can act on the block they’re assigned.
