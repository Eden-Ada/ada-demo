# Block 1 — Branding

Purpose: create the visual and verbal identity for the product with simple, demo‑friendly steps.

## Research Block — Style & Creative Direction (Vibe Carousel)
- Runs first. Ada proposes 3–5 “vibes” as styled templates in a carousel.
- User selects a vibe; this choice informs naming and all downstream assets (logo, typography, moodboard).
- Output: selected vibe and brief notes (tone, contrast, motifs, motion).

### Demo Selection — Vibe 1: Artsy
- Rationale: handmade/gestural feel, painterly textures, gallery/atelier tone.
- Visual cues: brush strokes, paper grain, soft glow; playful color with tasteful contrast.
- Downstream impact: steers naming toward Studio/Atelier/Pigment/Canvas/Brush/Loom language; TLD tilt to .studio / .art when .com is congested; logo favors painterly icon/iconogram.

## Research Block — Name Check (Marketable vs Style‑aligned)
- What runs
  - Based on the chosen vibe, Ada generates two sets of candidate names:
    - Marketable set: high memorability, pronounceable, broad appeal, domain viability.
    - Style‑aligned set: tightly connected to the selected vibe’s motifs/imagery/tone.
  - Checks domain availability (common TLDs) and quick conflicts (basic trademark/handle sniff).
- Decision Pane
  - Two columns: Marketable vs Style‑aligned, each with short rationales and domain candidates.
  - User selects a single name from either set; this locks the working name for the demo.
- Output
  - Chosen name and domain candidate (e.g., Pixelthread → pixelthread.com).

### Demo Candidates (Artsy)
- Marketable
  - Brushline — crisp, easy to say; evokes a brush stroke. Domains: .co/.studio likely open. Handles: generally free. Risk: Low.
  - Pixelthread — digital + apparel cue; modern. Domains: .co likely open; .com crowded. Risk: Medium (tech collisions).
  - Gallery Tee — straightforward, retail‑friendly. Domains: .co likely open. Risk: Medium (descriptive).
- Style‑aligned
  - Studio Loom — atelier + textile; warm and artisanal. Domains: .studio likely open. Risk: Low.
  - Pigment & Thread — painterly/material. Domains: .art/.studio likely open. Risk: Low (longer name).
  - Canvas & Thread — literal/clear. Domains: .art likely open. Risk: Medium (descriptive).

Notes
- Domain/handle results above are simulated for the demo. Real checks will vary by region/time.

## Task Item 1 — Logo Generation (Automation + Iteration Loop)
- Ada generates 3 logo options from the chosen name + vibe.
- Iteration loop (demo emphasis): user Regenerates or Nudges (weight/spacing/icon tweak) until approved.
- Output: approved logo assets (SVG/PNG), favicon, simple lockups.

## Task Item 2 — Typography & Color → Prompt Override to “Moodboard & Typography” (Outsourcing via Fiverr)
- Demo: start as “Typography & Color” to show Prompt Override in action.
- Prompt Override: rename to “Moodboard & Typography” (a clearer deliverable for branding).
- Outsourcing agent
  - Composes a Fiverr brief from name + vibe + approved logo.
  - User sets budget and scope for the gig (amount, revisions, timeline) and confirms.
  - Payment Block: user drags it in from the right-side pane to fund/escrow the job.
  - Artificial time passage: display a 2‑day meter during the job.
  - Delivery: moodboard tiles + type pairing suggestions arrive; user Accepts or requests edits.
- Output: approved moodboard and selected typography; preliminary color swatches.

## Task Item 3 — Insource: Brand Tagline & Summary (User Upload)
- Insource agent opens; user uploads a short doc with existing brand notes.
- Ada scans the upload, drafts the tagline + summary, and updates subsequent task items as needed.
- Output: concise brand narrative incorporated into the kit.

## UI flow notes
- Only one task is active at a time; the next task is shown faded beneath it.
- Research decisions immediately activate the next step.
- Payment Block appears in the right tray and is dragged in when outsourcing is used.
